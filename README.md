To have a proper omlx theme and colors, you will need to use git and clone a repo, from https://github.com/streetturtle/awesome-wm-widgets.git.
These are streetturtles awesome wm-widgets. You will also need the debrosee font, and awesome.ttf fonts

theme.lua goes into folder /usr/share/awesome/OpenMandriva/themes (replace file in that folder)
